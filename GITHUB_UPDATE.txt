WICHTIG: Für die iPhone-App-Version müssen diesmal ALLE neuen PWA-Dateien kopiert werden.

Kopiere aus Version 1.6.0 in dein lokales Repository:
- index.html
- manifest.webmanifest
- sw.js
- apple-touch-icon.png
- icon-192.png
- icon-512.png
- favicon-32.png

Dann in CMD:

cd /d C:\Astro\GAA\gavvas-astro-analyzer-1.2.0
git add index.html manifest.webmanifest sw.js apple-touch-icon.png icon-192.png icon-512.png favicon-32.png
git commit -m "Gavvas Astro Analyzer 1.6.0 - iPhone App PWA"
git push

Danach auf dem iPhone in Safari die GitHub-Pages-Seite öffnen:
Teilen -> Zum Home-Bildschirm -> Hinzufügen
