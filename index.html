World Atlas 2015

wird geladen
Die App liest automatisch data/world_atlas_2015.json und data/world_atlas_2015.bin. Aus der künstlichen Zenit-Himmelshelligkeit wird mit einem natürlichen Hintergrund von 0,174 mcd/m² ein geschätzter SQM-Wert und daraus eine geschätzte Bortle-Klasse berechnet.

Auf GitHub Pages wird nach Möglichkeit nur die benötigte Rasterzelle per HTTP-Range geladen. Falls der Server keine Range-Anfragen unterstützt, wird die 39,8-MB-Datei einmalig geladen und vom Browser zwischengespeichert.
Daten: World Atlas 2015 (Falchi et al.), Open‑Meteo, 7Timer!, Where the ISS at?, WhereTheISS.at TLE/satellite.js, OpenStreetMap/Leaflet, International Meteor Organization (Meteorstrom-Kalender). Astro-Index 2.0 folgt der PC-Bewertungslogik; Bortle ist eine Orientierungshilfe. Astronomische Zeiten werden standortbezogen berechnet.
